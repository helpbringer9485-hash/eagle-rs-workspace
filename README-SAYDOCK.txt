SAYDOCK / EAGLE RS — Practical interoperability
================================================
SayDock is an independent quick-reply utility that can attach to recognized desktop chat windows.
Its official changelog lists Telegram Desktop support; this does not imply support for Electron
webviews embedded inside EAGLE RS.

To use it:
  1. Install/update SayDock from https://saydock.com/download.html
  2. Open SayDock and configure its docking/attachment preferences.
  3. Start official Telegram Desktop, not EAGLE RS Telegram Web, for the documented compatibility path.
  4. Test SayDock quick replies in a conversation you control before use with customers.
  5. If SayDock disappears behind another app, use SayDock's own always-on-top/docking options.

This project does not install, control, capture, or inject into SayDock.
No automatic auto-attach capability is claimed across every chat app.
