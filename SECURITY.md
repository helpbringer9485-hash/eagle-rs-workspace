# Security

This is an unaudited experimental application. Do not rely on experimental native docking to securely conceal Signal content. Source review and real desktop tests are required before a stable release.

Do not turn off Smart App Control, antivirus or other protections to run unsigned binaries. A valid publisher signature establishes publisher identity; it does not prove that all app behavior is safe or correct.

Do not post secrets, recovery codes, private conversations or account databases in public issues. A private vulnerability reporting channel must be configured by the repository owner before accepting sensitive reports.
