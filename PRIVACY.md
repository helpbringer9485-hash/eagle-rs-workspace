# Privacy

Messaging browser sessions and Signal data remain on the user's computer. The app stores local account metadata, reminders and preferences, and uses Windows secure storage when available. Chromium session data and Signal profiles are not covered by the app's encrypted settings file.

Messaging services receive normal connection and authentication data when their services are used. Optional Google Gemini actions transmit the text and screenshots selected by the user when an AI action is pressed. Optional Google/Microsoft identity recovery and OneDrive backup contact those providers when configured and used. Provider terms and privacy policies apply. The app does not automatically send drafted replies to contacts.

The app uses public OAuth client identifiers; these are not client secrets. Do not include personal API keys or tokens in source or release artifacts. No user account profiles or private chat screenshots are included in this source package.

See https://policies.google.com/privacy and https://privacy.microsoft.com/privacystatement for those providers. Signal and WhatsApp publish their own privacy policies.
