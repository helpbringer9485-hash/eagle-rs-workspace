EAGLE RS COMPANY (Kings 2) — DIRECT HOTMAIL EMAIL CODES v3.23.0

This ZIP contains SOURCE CODE, not a prebuilt .exe.

QUICK WINDOWS BUILD
1. Save the ZIP, right-click > Extract All.
2. Close your old EAGLE RS app completely, including the system tray icon.
3. Double-click BUILD-WINDOWS.bat from the extracted folder (requires Node.js LTS).
4. When the build succeeds, open dist and run the EAGLE RS Workspace Setup installer.
5. Keep the existing EAGLE RS app data and offline recovery codes. Never uninstall with "delete all user data".

HOW EMAIL RECOVERY WORKS
- Initial setup: unlock with your existing EAGLE RS password; link Hotmail/Outlook via Microsoft's official browser sign-in, and approve the delegated "Send mail" permission (Mail.Send). Your already registered public Client ID is included. If the browser complains about the redirect URI, the app's Microsoft Entra registration needs the Mobile/Desktop http://localhost redirect configured once.
- Recovery afterward: at the lock screen press "Send recovery code to my email", then Send. A code generated by EAGLE RS is sent from your own Microsoft mailbox back to that SAME linked mailbox through Microsoft Graph. Check Inbox/Junk, enter the 8 digits and choose a new app password within 10 minutes.
- No Resend/Mailgun/Twilio/third-party email delivery vendor, SMTP password, client secret or API key is used for NEW Outlook email-code recovery.
- If your Microsoft permissions are revoked, connection expires, mail delivery fails, or you are offline, email recovery may not work. Keep your offline recovery codes.
- Old previously-configured Resend recovery records are not deleted by this migration. The legacy method remains in the advanced recovery selector only if it was already enrolled.
- Sending email from the linked account to itself requires the account to have an actual Outlook mailbox. A Microsoft identity using a Gmail address without an Outlook mailbox will not work for sending.
- Linking mail or resetting the local app passphrase does NOT restore WhatsApp, Signal or Telegram chats or provider logins, and does NOT change the mail account password.

WHAT IS TESTED
Automated tests validate local code generation, mock Microsoft Graph acceptance, correct linked recipient, permission-related errors, OTP never appearing in UI responses, wrong/expired/used codes, persistent email send rate limits, and preserved messaging storage names.

WHAT IS NOT TESTED
Real-world Microsoft Graph authorization and inbox delivery on your PC; Windows installer compilation. Do NOT rely on this recovery method until you've linked your account and successfully received a real test email.
